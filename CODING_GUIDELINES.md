# CODING GUIDELINES — SEE ENGINE & PRODUCTS

## Style

- Use modular, reusable code
- Separate engine vs product logic
- Document all functions with input/output

## Versioning

- Pin product repos to specific engine versions
- Use semantic versioning for engine and products

## Testing

- Unit tests for each module
- Integration tests for engine → product tracks
- Hardware-in-the-loop tests gated on review points
